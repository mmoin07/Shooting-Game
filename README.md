# Neon Arena Shooter

A top-down neon arena shooter built with plain **HTML, CSS and JavaScript** — no libraries, no build step.

## How to play

Open `index.html` in any modern browser.

| Control | Action |
| --- | --- |
| `W` `A` `S` `D` / Arrow keys | Move |
| Mouse | Aim |
| Left click (hold) | Shoot |
| `R` | Reload |
| `P` / `Esc` | Pause |

## Features

- Endless waves that get harder over time
- 4 enemy types: **Chaser**, **Runner**, **Tank** and **Shooter** (fires back)
- Power-ups dropped by enemies: **Health**, **Rapid fire**, **Spread shot**, **Shield**
- Ammo and reload system
- Particles, screen shake and synthesized sound effects (Web Audio)
- Best score saved in your browser

## Files

- `index.html` – page structure, HUD and menus
- `style.css` – neon styling for the HUD and overlays
- `game.js` – game loop, entities, collisions and rendering (canvas)
